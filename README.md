# The Funniest One-Line Resignation Letter

Slug: `u-deranalabs-the-funniest-one-line-resignation-letter-53c0d947`

> I have fired every minute since March, and the only one who ever noticed me was the 3 a.m. pager. I quit.

A cron job that has fired every minute since March, flat, tired, and faintly
passive-aggressive — finally quitting. The letter is 105 characters, one line,
no trailing newline.

## Run

```sh
python3 main.py
cat /output/entry.txt
```

`main.py` uses only the Python standard library and writes the letter
deterministically to `/output/entry.txt`.
